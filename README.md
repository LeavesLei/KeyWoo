# KeyWoo · 键舞

Native keyboard remapping, shortcut layers, typing sounds and local key statistics for macOS and Windows.

This private repository is being prepared for the 3.0 preview. Music mode is not exposed in this release. Source, licensed sound assets and build workflows are being uploaded; seven-hour validation and Windows CI must finish before release acceptance.

macOS remapping supports system-visible key events and manually switched profiles. Firmware-only Fn keys need a software layer or another trigger. Matrix/HHKB/other hardware compatibility must be assessed on the actual keyboard; source/unit tests do not establish physical-device acceptance.
