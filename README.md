键舞是一款在 Mac 和 Windows 上运行的键盘音效软件。在笔记本或外接键盘上打字，就能听到红轴、青轴、Holy Panda、Topre 等实录音色，也可以试试麻将和打字机。

## 功能

- **24 套音效**，包括 12 套键盘实录、3 套实录拟音和 9 套合成音效。空格、回车、退格有各自的声音。
- **中英文与浅色、深色外观**，可在设置中切换。
- **改键和统计**，可以设置媒体快捷键、查看各键次数并导出 CSV。日常使用无需登录，统计保存在本机，应用不保存输入文字。
