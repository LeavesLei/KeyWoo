# Windows 验证范围

## 1.0 发布准备（2026-11-06）

在 macOS 上以 .NET SDK 10.0.403 运行 56 项跨平台核心测试，全部通过。新增三个响度回归覆盖固定预设增益、原始 PCM 比例与起音位置、独立打字段落的音量差距，以及一个改键后的空格/物理媒体键声音与注入去重回归。Windows 现在与 macOS 使用同样的整套音量校准，不逐键压平真实差异。

WPF 交叉编译通过。安装器采用 Inno Setup 的当前用户安装，不要求管理员权限，不自动启动随开机，也不在卸载时删除个人设置和统计。`build.ps1 -VerifyInstaller` 会在 GitHub 临时 Windows runner 执行安装、再次安装、已安装 EXE 资源自检和卸载；实际 CI 结果以对应 run 和 `installer-tests/result.json` 为准，脚本存在不代表测试已执行。

默认输出切换重连、失败最多三次重试和设置里的手动重连已实现。真实键盘到声卡、蓝牙断连和默认输出切换的验收仍待实体 Windows 11 机器。没有恢复已取消的 7 小时测试。

## 历史预览验证

3.1 预览在 macOS 使用已校验的 .NET SDK 10.0.403 完成 WPF 交叉编译和 Windows x64 自包含发布，包含 .NET 10.0.14 运行时。跨平台核心测试 50 项全部通过。Windows 侧的最终 EXE 资源自检和桌面验收仍待执行。

3.2 的 52 项跨平台核心测试在同一 SDK 上全部通过，新增 1600% 音量、超范围限制和混音峰值验证。真机验收范围沿用下列清单。

自动化覆盖：

- 物理按下去重、注入事件隔离、主回车/小键盘回车独立；原始键统计不受映射影响。
- 单键 down/up、暂停释放与晚到 up、多个来源共用目标、真实目标键和映射目标交叠、修饰键临时解除和还原、注入失败降级、锁屏状态清理。
- 首次接管前已按住的目标/来源/右 Control、旧按压重复不计数或中途重绑、实际小键盘 Enter 松开可释放无扫描码的初始快照、解锁不沿用旧会话状态。
- 媒体键作来源，媒体、浏览器、启动应用作一次性目标，F24 作可持续目标。没有物理松开事件的 Pause 键每次生成完整轻按，并保留已按住的物理目标。
- 有界队列满载不覆盖，双生产者跨环回绕不撕裂/重复。
- 统计持久化往返、分钟边界、损坏旧文件保留与 CSV。
- 24 套音色实际 PCM 非静音且互异，其中 12 套键盘实录、3 套实录拟音、9 套合成。验证同一混音器切换音色、暂停/恢复、零音量、过载队列/声部上限、400% 峰值边界及 WAV 损坏检测。

核心测试使用两份采样 manifest。24 个 WAV 的 SHA-256、48kHz 双声道格式（PCM16 或 Float32）与帧数均由实际加载器检查。预览 ZIP 逐文件校验内容与打包目录一致，包内音效与核心测试使用的资产逐文件相同。

Windows CI 将实际执行测试、编译 WPF、自包含发布，然后运行最终 EXE 的无设备资源检查，并逐文件校验 ZIP 内容与 staging SHA-256。构建脚本不会开启全局 hook 或声卡；CI runner 不等于实体桌面验收。

仍需在实际 Windows 11 桌面验证：

1. 普通用户启动，24 音色全卡片可选择和试听，统计不因试听增长。实体快速打字与长按只计首次按下。
2. 文本编辑器/浏览器中全局反馈，左右修饰键、主/小键盘回车、IME；不借此声称密码框内容可读取。
3. Caps→Esc、Ctrl+Alt 媒体热键、真实媒体键作来源、F13–F24、Pause、自定义目标组合。来源和目标同时持有，或按住时暂停、改配置、退出时均检查按键释放。
4. 锁屏/解锁、关闭窗口继续托盘、再次启动只有一个实例；更高权限窗口被阻止时错误可见、正常原键可继续输入。
5. Windows 默认输出切换/断开设备、蓝牙/有线耳机的实际听感与延迟。当前代码的 WASAPI 延迟参数只是请求值，不是测量结果。
6. 浅色/深色/系统、中英文、不同 DPI、最小窗口与屏幕阅读器；选择配置后重启仍保留，统计范围翻译后不重置。

包未做 Authenticode 签名，不把 Windows CI 通过描述为用户听感接受或硬件按键到耳延迟通过。
