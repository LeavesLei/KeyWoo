# 安装与开始使用

[English](INSTALL.en.md)

## 选择下载包

打开 v1.0.2 发布页，展开 **Assets** 并选择对应的安装包。[KeyWoo v1.0.2](https://github.com/LeavesLei/KeyWoo/releases/tag/v1.0.2-build26)

| 电脑 | 下载 |
| --- | --- |
| Apple silicon Mac，macOS 14 或更新 | 标有 `mac-arm64` 的 DMG 或 ZIP |
| Windows 11，Intel / AMD 64 位处理器 | 标有 `win-x64` 的 `setup.exe` 或 ZIP |

请按文件名中的平台和架构选择。当前发行目标不包含 Intel Mac 或 Windows ARM64。

## Mac

1. 打开 DMG，将 **KeyWoo** 拖到 **Applications／应用程序**。使用 ZIP 时，解压后将应用移到「应用程序」。
2. 从启动台、Spotlight 或「应用程序」打开 **键舞 / KeyWoo**。
3. 在音效页点击音色卡，再在试听区打字。
4. 要在其他应用中发声，点击 **开启全局体验**，到「系统设置 → 隐私与安全性 → 输入监控」允许键舞。若列表未出现，可用「＋」添加「应用程序」里的 KeyWoo。
5. 如需改键，在改键页单独开启并按提示授予「辅助功能」权限。只使用音效时无需启用改键。

当前 Mac 版使用本地签名，尚未通过 Apple 公证。如果 macOS 提示无法验证开发者，先确认安装包来自 KeyWoo 发布页，再按 Apple 的说明在「隐私与安全性」中确认打开。[Apple 的打开应用说明](https://support.apple.com/en-us/102445)

关闭窗口后，应用继续在菜单栏运行。右上角 **全部暂停** 暂停声音、统计和桌面律动；改键有独立开关。要完全退出，使用菜单栏中的「退出」或 **⌘Q**。若映射不符合预期，可按 **Control + Option + Command + Escape** 紧急停用改键。

## Windows

1. 运行标有 `win-x64` 的 **setup.exe**，按提示完成当前用户安装。
2. 从开始菜单打开 **KeyWoo**，选择音色并打字试听。自包含包无需另装 .NET。
3. 如需改键，添加来源键、目标键及修饰键，再打开改键开关。播放／暂停、上一首和下一首等位于媒体键选项中。

便携版请先**完整解压** ZIP，再运行 `KeyWoo.exe`。保持 `Assets`、`Licenses` 和其他文件与主程序在同一目录，不能只取出一个 EXE。

当前 Windows 版尚未签名，首次打开可能显示未知发布者提示。请确认安装包来自 KeyWoo 发布页。受管理电脑的安装权限以所在组织的要求为准。

关闭窗口后应用保留在系统托盘。**全部暂停** 同时暂停声音、统计和改键；从托盘菜单选择「退出」才能完全退出。软件默认以普通用户权限运行，无法保证改写更高权限窗口或系统保留快捷键。

## 常见问题

**为什么有的 Fn 按下无声？** 许多键盘把 Fn 作为固件内部层切换键。它可能没有独立事件，而 Fn 组合键会输出媒体键。KeyWoo 只能响应电脑收到的事件，不能凭空识别未上报的按压。

**为什么耳机里的声音比敲击晚？** 反馈还会经过系统与音频设备。蓝牙耳机存在传输与缓冲延迟；有线耳机或内置扬声器通常更适合即时按键反馈。

**为什么改键设置不能跨平台直接导入？** Mac 使用 Quartz 键码，Windows 使用 Win32 键码与扫描码；两端配置分别保存。KeyWoo 的映射运行在电脑上，不修改键盘芯片。

**如何更新？** 先完全退出 KeyWoo，再安装新版本到原位置。保留相同应用身份与本机数据目录；安装不会要求清空统计。Mac 的权限是否保留由系统判断。

**如何卸载？** Mac 将「应用程序」中的 KeyWoo 移到废纸篓；Windows 安装版从「设置 → 应用」卸载，便携版退出后删除解压目录。统计与偏好设置属于本机数据，位置见[隐私说明](PRIVACY.md)。
