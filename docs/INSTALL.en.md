# Install and use KeyWoo

[简体中文](INSTALL.md)

Choose the file for your computer under **Assets**. [KeyWoo v1.0.2 release](https://github.com/LeavesLei/KeyWoo/releases/tag/v1.0.2)

| Computer | Download |
| --- | --- |
| Apple silicon Mac with macOS 14 or later | `mac-arm64.dmg` or `mac-arm64.zip` |
| Windows 11 PC with a 64-bit Intel or AMD processor | `win-x64-setup.exe` or `win-x64.zip` |

## Mac

1. Open the DMG and drag **KeyWoo** into **Applications**. For the ZIP, extract it first, then move the app into Applications.
2. Open KeyWoo, choose a sound, and type in the practice area.
3. For sound in other apps, click **Enable across apps**. Allow KeyWoo in **System Settings → Privacy & Security → Input Monitoring**.

The Mac preview uses a local signature and has not been notarized by Apple. If macOS cannot verify the developer, check that your download came from the release page, then follow Apple's instructions. [Apple's guide to opening apps](https://support.apple.com/en-us/102445)

Remapping requires a separate **Accessibility** permission. Use **Quit** in the menu bar or press **⌘Q** to exit KeyWoo.

## Windows

1. Run the installer and open **KeyWoo** from the Start menu. The installer includes the .NET runtime.
2. Pick a sound and use the **Try typing** area to preview it.

For the portable version, extract the entire ZIP and run `KeyWoo.exe` from the extracted folder. The Windows preview is unsigned and may show an unknown publisher prompt. Check that the file came from the release page.

KeyWoo stays in the system tray when you close the window. Select **Quit** from its tray menu to exit.

## Update or uninstall

Quit KeyWoo before installing an update. On Mac, remove the app from Applications to uninstall. On Windows, use **Settings → Apps** for the installer version or delete the extracted folder for the portable version. Your settings and key counts are stored separately.
