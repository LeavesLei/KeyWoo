# KeyWoo v1.0 发布候选

**键舞以机械键盘音效为主功能，给日常打字增加自然、清晰的声音反馈。**

这是首次以 v1.0 整理的对外版本。此前 3.x 为本机开发预览编号；应用名称仍为键舞 / KeyWoo，本机数据保持兼容。

## 包含内容

- 12 套键盘实录：Cherry 红／青／茶／黑轴的不同键帽版本、Everglide Oreo、水晶紫、Topre、Holy Panda 和 MacBook Pro 键盘。
- 3 套实录拟音：麻将牌、Hermes 打字机和木桌敲击。
- 9 套独立标注的合成趣味音效。大小键采用不同音色或采样池；按键松开的声音以源录音实际可用内容为准。
- 音色整体响度匹配、可调音量、峰值保护与预加载采样。
- 电脑侧改键与组合键，包含播放／暂停、上一首和下一首等媒体功能。
- 本机逐键统计、时间段查询和 CSV 导出。
- 中英文、浅色／深色／跟随系统；Mac 提供可选桌面律动。

音乐模式不在本次发布功能中。Mac 和 Windows 共享音效资产，界面与系统改键实现分别适配各自平台，配置文件不能跨平台直接交换。

## 发行范围

| 项目 | 范围 |
| --- | --- |
| Mac | macOS 14+，Apple silicon；DMG / ZIP |
| Windows | Windows 11 x64；当前用户安装器 / 便携 ZIP |
| 下载 | [GitHub v1.0.0 发布页](https://github.com/LeavesLei/KeyWoo/releases/tag/v1.0.0) |
| Mac 签名 | 固定本地签名，尚未通过 Apple 公证 |
| Windows 签名 | 尚未 Authenticode 签名 |

实体 Windows 键盘、声卡与桌面交互验收尚未完成。即使 Windows CI 构建、核心测试和最终 EXE 资源自检通过，也不代表实体设备延迟、音质或所有键盘兼容性已经通过。最终各包的构建结果、版本和 SHA-256 应随该次 GitHub Release 一并列出；本说明不代替结果记录。

外接键盘的固件 Fn 可能不向系统上报独立事件；部分系统保留键不能映射。Mac 的「全部暂停」暂停声音、统计和律动，改键为独立开关；Windows「全部暂停」也暂停改键。
